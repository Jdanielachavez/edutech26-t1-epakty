# Referencias públicas normalizadas

Los CSV se normalizan desde publicaciones oficiales y conservan fuente,
período y fecha de extracción para mantener trazabilidad. Los datos agregados
se usan como contexto institucional; no se enlazan a estudiantes individuales.

- AMIE / Ministerio de Educación: registro histórico fin 2009–2024, descargado
  desde Datos Abiertos y agregado por período, provincia, sostenimiento, tipo de
  educación, área y régimen.
- ENEMDU / INEC: tasas agregadas de desempleo y pobreza por ingresos, usando
  los tabulados anuales 2025. Catálogo oficial:
  <https://www.ecuadorencifras.gob.ec/enemdu-anual/>
- INEVAL: boletín de factores asociados de Ser Estudiante 2024–2025, subnivel
  Básica Superior. Se almacenan distribuciones publicadas por opción de
  respuesta como contexto; no son efectos causales ni observaciones del colegio.

ENEMDU no identifica al hogar de un estudiante del colegio. INEVAL publica
encuestas/resultados poblacionales. Ambos se usan para contexto o calibración
institucional con sus ponderadores y metodología, nunca para atribuir ingresos,
bienestar o probabilidades a una persona.
